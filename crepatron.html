Ejercicio 1/5
Puntuación: 0/5

¿Cuál de las siguientes opciones completa correctamente el patrón creciente?

Estrategia para resolver

Observa cómo cambia cada elemento en relación con el anterior. Identifica si el cambio es constante o si sigue una regla específica.

Solución

La respuesta correcta es la opción C. El patrón sigue una progresión geométrica donde cada elemento es el doble del anterior más uno.
